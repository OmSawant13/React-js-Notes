🚨 2. Top 10 React Traps & Anti-Patterns (Interviewer Favorites)
Trap Bura Code (❌) Sahi Code (✅) Kyu Hota Hai?
1. Direct State Mutation state.count = 5; setCount(5); Direct mutation se React ka re-render trigger nahi hota!
2. Stale Closure in Count setCount(count + 1);
setCount(count + 1);		 setCount(p => p + 1);
setCount(p => p + 1);		 Purana count closure me capture ho jata hai. Functional update latest state use karta hai.
3. Index as Key {items.map((it, i) => <Item key={i} />)} {items.map(it => <Item key={it.id} />)} Item delete/reorder hone par index badal jata hai aur wrong DOM state reuse ho jati hai.
4. Zero in Conditional JSX {count && <Badge />} {count > 0 && <Badge />} JS me 0 && ... screen par number 0 print kar deta hai!
5. Inline Object in Memo <MemoChild style={{ color: 'red' }} /> const style = { color: 'red' };
<MemoChild style={style} />		 Har render pe naya object reference banta hai, shallow comparison fail hoti hai!
6. Missing useEffect Cleanup useEffect(() => { setInterval(...); }, []) useEffect(() => { const id = ...; return () => clearInterval(id); }, []) Component unmount hone ke baad bhi interval chalta rehta hai (Memory Leak!).
7. Infinite Loop in useEffect useEffect(() => { setCount(c + 1); }) useEffect(() => { ... }, [dep]) Dependency array miss karne se state update ➡️ re-render ➡️ effect ➡️ infinite loop!
8. Calling Hook in Condition if (isAuth) { useState(...); } Always call hooks at top level! React Fiber linked list ka pointer hil jata hai aur app crash ho jati hai.
9. Modifying Props in Child props.user.name = "New"; Props are strictly READ-ONLY! Pass callback to parent. Props immutable hote hain, unhe mutate karne se parent ka state corrupt hota hai.
10. Async Function directly in useEffect useEffect(async () => { await ... }) useEffect(() => { async function get() { ... } get(); }, []) useEffect sirf cleanup function return kar sakta hai, Promise return nahi kar sakta!
💥 3. Common Console Errors & 1-Line Debugging
🔬 Error Anatomy & Instant Fixes DEBUGGING
🔴 ERROR 1: "Too many re-renders. React limits the number of renders to prevent an infinite loop."
👉 FIX: Tumne onClick me function pass karne ke bajay call kar diya: `onClick={handleClick()}` ➡️ Badlo: `onClick={handleClick}` ya `onClick={() => handleClick(id)}`.
─────────────────────────────────────────────────────────────────────────────
🔴 ERROR 2: "Rendered fewer hooks than expected. This may be caused by an accidental early return statement."
👉 FIX: Tumne kisi hook ke pehle `if (!user) return null;` laga diya. Hooks hamesha top par call karo, early return baad me karo!
─────────────────────────────────────────────────────────────────────────────
🔴 ERROR 3: "Each child in a list should have a unique 'key' prop."
👉 FIX: `map()` ke return element par `key={item.id}` dena bhool gaye.
─────────────────────────────────────────────────────────────────────────────
🔴 ERROR 4: "Hydration failed because the initial UI does not match what was rendered on the server."
👉 FIX: Server aur Client ka HTML alag hai (e.g. `window.innerWidth`, `Math.random()`, ya `new Date()` render kiya). Use `useId()` ya `useEffect` me client state set karo.
─────────────────────────────────────────────────────────────────────────────
🔴 ERROR 5: "Cannot update a component while rendering a different component."
👉 FIX: Parent ki state ko child ke render function body ke andar direct call kar diya. Usse `useEffect` ya event handler ke andar move karo.
