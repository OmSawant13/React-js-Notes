React Router v6 Senior / 8-10 LPA

Q: What is the purpose of the component in React Router v6?

Answer: An <Outlet /> is a placeholder element used in parent layout route components to render their child route elements. When the URL matches a nested child path (e.g. /dashboard/settings), the parent layout (with persistent navbar and sidebar) stays rendered, and React Router dynamically swaps the matched child component directly inside the slot.
Auth Guards High Frequency

Q: How do you implement a Protected Route in React Router v6?

Answer: By creating an Auth Guard wrapper component that checks the user's authentication state (e.g. JWT token in memory or context). If authenticated, it renders (allowing child routes to render); if unauthenticated, it returns to redirect the user to the login screen without polluting browser history.
Params Core Concept

Q: What is the difference between useParams and useSearchParams?

Answer: useParams extracts dynamic URL segment parameters defined in the route pattern (e.g., /users/:id ➡️ { id: "123" }). useSearchParams reads and updates query string parameters appended after a question mark (e.g., /search?query=react&page=2 ➡️ searchParams.get("query")).
