💧 1.2 Hydration & The Dreaded Hydration Mismatch Error

Hydration is the process where React takes the pre-rendered static HTML received from the server, matches it with the VDOM, and attaches interactive JavaScript event listeners (clicks, inputs) to the existing DOM nodes.

🔬 Bio-Anatomy: Why Hydration Mismatch Errors Happen HYDRATION BUG
Server Renders HTML:
<p>Timestamp: 10:45:00 AM</p> ──▶ Sent to browser
─────────────────────────────────────────────────────────────────────────────
Browser Hydrates 3 seconds later:
Client runs new Date().toLocaleTimeString(): "10:45:03 AM"
💥 REACT FATAL WARNING: "Hydration failed because the server-rendered HTML didn't match the client!"
─────────────────────────────────────────────────────────────────────────────
✅ FIX: Only access client-specific APIs (window, localStorage, Date) inside useEffect()!
