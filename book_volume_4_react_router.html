📌 1.1 Client-Side Routing Mechanics

In traditional multi-page apps, clicking a link issues a full HTTP GET request to the server, reloading the whole page (blank white flash). In React Single Page Applications (SPA), Client-Side Routing (CSR) intercepts URL clicks via the HTML5 History API (pushState / replaceState), swapping out components in the VDOM without requesting a new HTML page from the server.

💻 1.2 Practical Code: Protected Routes & Auth Guards Pattern
AppRouter.jsxProduction React Router v6
import { BrowserRouter, Routes, Route, Navigate, Outlet, useLocation } from "react-router-dom";

// 1. Protected Route Guard Component
function ProtectedRoute({ isAuthenticated }) {
    const location = useLocation();

    if (!isAuthenticated) {
        // Redirect to login, but preserve the attempted URL to redirect back after login!
        return <Navigate to="/login" state={{ from: location }} replace />;
    }
    return <Outlet />; // Renders the matching child route if authenticated!
}

// 2. Master Route Configuration
function App() {
    const isAuth = true; // In real app, consume from useAuth() hook

    return (
        <BrowserRouter>
            <Routes>
                <Route path="/login" element={<LoginPage />} />

                {/* Protected Subtree */}
                <Route element={<ProtectedRoute isAuthenticated={isAuth} />}>
                    <Route path="/dashboard" element={<DashboardLayout />}>
                        <Route index element={<Overview />} />
                        <Route path="jobs/:id" element={<JobDetail />} />
                        <Route path="settings" element={<Settings />} />
                    </Route>
                </Route>

                <Route path="*" element={<NotFound404 />} />
            </Routes>
        </BrowserRouter>
    );
}

Q: What is the difference between Link, NavLink, and useNavigate in React Router?

Key Answer:
  • <Link to="/path">: Standard declarative navigation that renders an accessible <a> tag and updates the URL without page reloads.
  • <NavLink to="/path">: Specialized Link that automatically knows if its URL matches the current active route, injecting an isActive boolean prop for styling active navigation pills.
  • useNavigate(): Programmatic imperative navigation hook used inside event handlers (e.g. redirecting after successful form submission: navigate('/dashboard')).
