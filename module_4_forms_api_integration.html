1. Controlled vs Uncontrolled Components
📌 1.1 Papa ka Ladla vs Hostel ka Mast-Maula
👨‍👦 Desi Analogy

• Controlled Component: Papa ka Ladla! Har kadam pe React state se permission leta hai (value={name} onChange={e => setName(e.target.value)}). React ko har ek keystroke ki khabar hoti hai.

2. Handling Multiple Inputs with a Single State Object
📌 2.1 The Dynamic Computed Property Name Pattern `[name]: value`

Agar form me 10 inputs hain, toh kya 10 alag useState banaoge? Bilkul nahi! Ek single object state banao aur input ke name attribute se dynamically key update karo:

MultiInputForm.jsxPro Pattern
import { useState } from 'react';

function RegistrationForm() {
    const [formData, setFormData] = useState({
        username: "",
        email: "",
        password: "",
        role: "developer"
    });

    const handleChange = (e) => {
        const { name, value } = e.target;
        // Computed Property Syntax: [name] dynamically evaluates to "username", "email", etc.
        setFormData(prev => ({
            ...prev,
            [name]: value
        }));
    };

    const [password, setPassword] = useState("");

4. Fetch API vs Axios
📌 4.1 Comparison & Why Production Uses Axios
Feature Native Fetch API Axios Library
Installation Built-in in browser (No npm install) npm install axios
JSON Parsing Manual: await res.json() karna padta hai Automatic! Direct res.data milta hai
HTTP Error Handling 404 ya 500 par bhi promise reject nahi hoti! Auto Rejection! 4xx/5xx seedha catch block me jata hai
Interceptors & Timeout Nahi hota (manually wrapper likhna padta hai) Built-in Interceptors (Auth token refresh ke liye best)
5. HTTP Verbs: GET, POST, PUT, PATCH, DELETE
📌 5.1 Restful API Conventions
  • GET: Server se data mangwana (Read operation, no body).
  • POST: Server par naya resource create karna (Create operation, sends JSON body).
  • PUT: Poore resource ko completely replace karna (Complete update).
  • PATCH: Sirf specific fields ko update karna (Partial update, e.g. status: "active").
  • DELETE: Resource ko delete karna.
6. Environment Variables in Vite
📌 6.1 `import.meta.env` Standard

Create-React-App me process.env.REACT_APP_... use hota tha. Modern Vite me:

  1. Root directory me .env file banao.
  2. Har variable ke aage VITE_ prefix compulsory hai! (e.g. VITE_BACKEND_URL=http://localhost:5000/api).
  3. React code ke andar access karo: const API_URL = import.meta.env.VITE_BACKEND_URL;.

💼 Module 4 Interview Bank (Sudheer J Style)
Forms Fresher / 4-6 LPA

Q: What is the exact difference between Controlled and Uncontrolled Components in React forms?

Answer: In a Controlled Component, the form input element's value is controlled by React state (`value={state}` + `onChange={setState}`). React state serves as the "single source of truth". In an Uncontrolled Component, form data is handled by the browser DOM itself, and values are pulled on demand using `useRef` (e.g. `ref.current.value`). Controlled components are preferred for real-time validation and dynamic inputs.
HTTP Verbs High Frequency

Q: What is the difference between PUT and PATCH HTTP requests?

Answer: PUT replaces the entire resource; any fields omitted in the request payload will typically be overwritten or set to null. PATCH performs a partial update; it only modifies the specific fields sent in the request payload without touching the rest of the existing resource.
Axios vs Fetch Interview Classic

Q: Why do top engineering teams prefer Axios over the native Fetch API?

Answer: Axios provides: (1) Automatic JSON data transformation (no need for `res.json()`), (2) Automatic error rejection for HTTP status codes outside 2xx (Fetch does not reject 404 or 500), (3) Request and Response Interceptors for seamless JWT token refresh handling, (4) Built-in request timeout support, and (5) Built-in XSRF/CSRF protection.
